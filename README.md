## Selected Projects

### 1. [CrimeVista AI — Crime Intelligence Analytics](https://github.com/parthrathicode/CrimeVista-AI)
**Python · FastAPI · React · SQLite · XGBoost · DBSCAN · NetworkX · SHAP**

A full-stack analytics prototype developed for the **Karnataka State Police Datathon 2026**. It brings together multiple analytical workflows in one dashboard:
- Spatial hotspot analysis using DBSCAN / ST-DBSCAN concepts.
- Network and relationship analysis with NetworkX and community detection.
- District-level crime forecasting with XGBoost and SHAP explanations.
- Anomaly detection using Isolation Forest, with API-driven dashboard visualizations.

<sub>Prototype note: the repository documents a seeded/synthetic data workflow; it is not an operational police deployment.</sub>

### 2. [RTOS Simulator & Live System Monitor](https://github.com/parthrathicode/rtos-live-system-monitor)
**C · Windows API · Winsock · React · TypeScript**

A systems project that connects low-level Windows telemetry to a browser-based monitoring interface.
- Collects CPU, memory, and process information through Windows APIs.
- Exposes system metrics through a lightweight C HTTP server and REST endpoints.
- Maps live process information into a conceptual RTOS task model for visualization.

### 3. [Activity Point Management System](https://github.com/parthrathicode/Activity-Point-Management-System)
**React · Firebase Authentication · Cloud Firestore · JavaScript**

A role-based platform designed to digitize student activity-point workflows at RVCE.
- Supports five roles: Dean, HOD, Club, Counsellor, and Student.
- Implements activity proposal, multi-level review, point allocation, and verification workflows.
- Provides role-specific dashboards and downloadable student reports.

### 4. [SmartOrder — Intelligent Food Delivery Scheduling](https://github.com/parthrathicode/SmartOrder)
**React · TypeScript · C · Data Structures & Algorithms**

A food-delivery scheduling simulation focused on applying core DSA concepts to practical workflow problems.
- Priority scheduling with a max-heap and starvation prevention through aging.
- Route planning using Dijkstra's shortest-path algorithm.
- Trie-based restaurant autocomplete, Union-Find zone grouping, and LRU caching.

### 5. [DDoS Network Intrusion Detection](https://github.com/parthrathicode/network-intrusion-ddos-detection)
**Python · Pandas · NumPy · Scikit-learn · Statsmodels · Jupyter**

A reproducible ML workflow for classifying benign and DDoS network flows using Logistic Regression on the CICIDS2017 benchmark dataset.
- Cleans and explores network-flow data, including missing/infinite values and duplicates.
- Studies skewness, outliers, correlations, and multicollinearity using VIF.
- Uses a stratified train/test split and training-only feature scaling to avoid data leakage.
- Evaluates the classifier with accuracy, precision, recall, F1-score, and a confusion matrix.

### 6. [Bank Loan Approval Prediction](https://github.com/parthrathicode/bank-loan-prediction) · [Telco Customer Churn](https://github.com/parthrathicode/telco-customer-churn-prediction) · [House Price Prediction](https://github.com/parthrathicode/house-price-prediction)
